# Données du cours

`patients.csv` est un jeu de données **entièrement synthétique**, créé pour les exercices du cours. Il ne contient aucune donnée de patient réel.

Variables : identifiant, âge, sexe, groupe, taille, poids, tension artérielle systolique (TAS), température, statut tabagique, traitement, score et date de visite. Quelques valeurs manquantes ont été introduites volontairement.
